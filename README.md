# Hire Horizon Insights

demanda 
Vamos focar no que temos hoje, agrupar as opções de dashs em Candidatos, Vagas, Empresas e Processos - Criar um padrão de layout, gráficos e tipografia para aplicarmos futuramente nos demais módulos.

Avaliar as sugestões do cliente para adicionar dentro das dashs no formato mais adequado.




A ideia aqui é melhorar a questão de gráficos, olhando assim, os gráficos estão bem antigos, trazer insights melhores. Eu tenho várias informações de candidatos, vagas, processo seletivo, então essa é uma dashboard do módulo de recrutamento e seleção. Onde entra toda essa parte de candidatos, vagas, recrutamento, o processo seletivo. Tem também várias outras coisas relacionadas a estágio. Então eu preciso de uma dashboard mais informativa, com uma análise bem mais completa e atualizada. Sobre o header acima, o botão de menu, isso continua igual, porque é a estrutura do sistema, mas a dashboard em si precisa ser criada. De uma forma melhor, bem melhor apresentada, com mais informações relevantes para o administrador que utiliza a ferramenta, que é um recrutador.

Com base nisso, monte um protótipo onde eu consiga já visualizar o gráfico com algumas informações relevantes, agrupado conforme a demanda solicita e, em termos de funcionalidade, eu tenho que conseguir clicar nas abas e conseguir ver o conteúdo de cada uma com os seus gráficos, com as suas informações relacionadas, tá? Eu faço isso de forma respeitando o layout original do sistema, a estrutura original, só trazendo a dashboard inovada, casando certinho com a estrutura base do sistema.
