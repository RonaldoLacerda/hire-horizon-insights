# Hire Horizon Insights

Protótipo de dashboard de Recrutamento e Seleção com indicadores de candidatos, vagas, empresas e processos seletivos.

## Desenvolvimento local

Requisitos: [Bun](https://bun.sh/).

```sh
bun install
bun run dev
```

Para executar os testes e gerar o build:

```sh
bun test
bun --bun run build
```

## Publicação

O projeto é publicado no GitHub Pages após cada push para `main`:

https://ronaldolacerda.github.io/hire-horizon-insights/

O protótipo usa dados demonstrativos e não é conectado a um serviço de recrutamento.
